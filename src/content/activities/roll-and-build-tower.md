1. **Hand out the blocks.** Give each player a pile of 20 to 40 blocks and set a target number, like 10 or 20.
2. **Roll and count the dots.** One player rolls the die. Touch each dot together and say the number out loud.
3. **Stack that many blocks.** Count each block as it goes onto the tower: one, two, three.
4. **Count the whole tower.** After each turn, count the tower from the bottom up, touching each block.
5. **Take turns.** Pass the die to the next player. The first tower to reach or pass the target wins. If a tower falls, count what fell and rebuild.
6. **Celebrate the total.** Announce how many blocks the tower holds before you knock it down or start again.
