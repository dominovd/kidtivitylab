1. **Build the tree together.** Cut a cardboard tree, paint it green, let it dry.
2. **Cut and color the holes.** Ball-sized holes, each rimmed with a different color.
3. **Mount it.** Fix the tree to an open box so the balls collect behind.
4. **Demonstrate one match.** Red ball, red hole, push, THUNK.
5. **Leave it standing.** It's decor now, the game restarts itself every time a small person walks past.
