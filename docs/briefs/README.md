# Брифы статей блога: общие требования

Брифы по одной статье в файле. Здесь то, что общее для всех. Список тем и приоритеты: проект kidtivitylab.com, документ `claude/blog-backlog.md`.

## Язык и тон

- Статья на американском английском для родителей в США. Всё, что идёт на страницу и на картинки, на английском. Бриф на русском.
- Родитель говорит с родителем: «we», «you», сокращения (you're, it's), абзацы до 3 предложений.
- 2–3 сцены из быта с возрастом ребёнка и точные фразы, которые можно сказать ребёнку.
- Без чувства вины у родителя и без морализаторства.
- Запрещено: длинное тире; слова delve, navigate the complexities, in today's digital age, it's important to note, unlock, embark, tapestry, crucial, game-changer, empower, holistic, journey, «In conclusion»; придуманные цитаты, эксперты, статистика; «Reviewed by» без реального рецензента.

## Структура

- Ответ на вопрос из заголовка в первых 2–3 предложениях.
- Сразу после него блок `> **Quick answer**` на 5 пунктов.
- Число пунктов в списке совпадает с числом в URL и H1 (25 поделок = ровно 25).
- У каждого пункта списка: возраст, время, материалы одной строкой, 2–4 предложения «как», при необходимости строка про безопасность.
- В конце `## Common questions`: 4 вопроса из People Also Ask.
- Title до 60 символов, description 140–155.

## Источники

- Каждая цифра и каждое утверждение о здоровье или развитии со ссылкой в тексте на первоисточник из брифа. Других цифр не добавлять.
- Список источников в frontmatter (`sources`); на странице он выводится текстом, без ссылок.
- Исследования подавать как связь, а не как причину.

## Перелинковка

- Активность с сайта, которая совпадает с пунктом списка, ссылается на свою страницу: `[Freeze Dance](/activities/freeze-dance/)`. Не пересказывать её целиком: 2–3 предложения и ссылка.
- 5–8 активностей в `related_activities` (карточки внизу статьи), только существующие слаги.

## Картинки

- Стиль как у обложек блога: тёплая плоская иллюстрация, кремовый фон, приглушённые коралловый, шалфейный и охра, без радуг, брендов и экранов с узнаваемыми играми.
- Обложка 1600×900 WebP до 200 КБ + версия 800×450. В тексте 2–3 картинки или инфографики. Пин 1000×1500 с крупным заголовком.
- Перед сохранением пересжать в WebP с качеством около 80: новые картинки выходили 180–240 КБ.
- Alt на английском, 8–15 слов.
- Папка: `public/images/blog/<slug>/`. PDF: `public/downloads/`. Исходники SVG и скрипты: `scripts/blog-assets/`, не в `public/`.

## Публикация

1. Черновик уже лежит в `src/content/blog/<slug>.md` с `draft: true`. Текст вставить после frontmatter, заполнить `lede`, `hero_alt`, дополнить `sources`.
2. Картинки и PDF в папки выше.
3. `draft: false`, реальная дата `published`, коммит, пуш.

## Чек-лист перед публикацией

- [ ] Title до 60 символов, description 140–155, число пунктов совпадает с H1
- [ ] Ответ в первых 3 предложениях, Quick answer, 4 вопроса в конце
- [ ] Все цифры сверены с источниками из брифа, ссылки открываются
- [ ] Нет длинного тире, запрещённых слов и TODO
- [ ] Безопасность у каждого пункта с водой, резкой, мелкими деталями или химией
- [ ] Обложка, картинки в тексте, пин, PDF (если есть); у всех картинок alt
- [ ] Ссылки на активности сайта ведут на существующие страницы
